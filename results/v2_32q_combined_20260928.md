# 32-logical-qubit extension: combined result

This report records the first 32q implementation with a 1-second beam attempt. A later [paired A/B and 40/48/64q smoke study](v2_40_48_64_smoke_20260928.md) found that beam never finished at 32q and is now disabled by default above 24q. The gate-count results below remain the baseline comparison. A larger 64q study was completed later; see its [research report](v2_64q_research_report_20260928.md).

The frozen 16–24q baseline is archived in [v2_frozen_16_24_20260928.zip](v2_frozen_16_24_20260928.zip). The 32q extension kept the same line-routing and beam-search policy. It added a wide integer score for Rust's initial line ordering above 30 qubits and enabled the existing line-route tournament at 32q. The 16–24q line path and Rust score/search source were preserved.

Smoke tests ran first on graph IDs 99500 and 99501. Both medium50 and dense75 with one and two QAOA layers completed on FakeBrisbane. Symbolic route checks, compiled final mapping checks, target-native 2Q checks, and RAM checks passed. Only after that were the fresh graph IDs 99600–99604 and 99700–99704 benchmarked. The second 60-case run used the final Rust build, which separated the unchanged <=30q search from the new wide-score branch. No 32q routing rule was tuned between runs.

The benchmark contains **40 distinct 32q logical circuits**, each compiled on full FakeBrisbane, FakeKyiv, and FakeSherbrooke snapshots: **120 paired cases**. Stock Qiskit Level 3 is a secondary reference. Qiskit `Commuting2qGateRouter` + SAT placement is the main competitor. The SAT feasibility limit is 2 seconds per check. All figures below come from local compilation, not real QPU execution.

The 120 target-specific cases represent 40 different logical circuits. Hybrid won on **35/40 distinct circuits** by native 2Q count. Its mean measured compile time was **1.84 s**, versus **3.84 s** for commuting + SAT and **0.34 s** for Stock. These timings include the benchmark's routing checks, so they are not pure production compile times. Peak process RAM was **314 MiB**. All 120 selected routes were the Rust optimized-line candidate.

The depth result is mixed. Medium50 depth improved by 7.2%. Dense75 depth was 0.3% worse overall, mainly because one-layer dense circuits had 2.9% greater depth. Hybrid therefore does not dominate specialized Qiskit on every metric or circuit.

Correctness checks: **240/240 candidate route symbolic replays** and **120/120 selected compiled mapping checks** passed. The replay validates SWAP and ZZ gate order, final logical placement, and coupling edges. Every recorded two-qubit native gate is supported by the target. No full 32q statevector, MPS compiled-output simulation, or real-QPU run was performed; those claims remain unverified.

The same memory-safe benchmark script accepts 40, 48, and 64 logical qubits. A physical line of each length was found on all three snapshots, and the Rust line-order optimizer accepted complete interaction graphs of each length (780, 1,128, and 2,016 edges). Later smoke tests covered all three sizes, and a larger paired benchmark covered 64q; 40q and 48q still have only small paired probes. Six representative 16–24q cases matched the frozen baseline's native 2Q count and 2Q depth exactly after the extension.
